# PetroOps Command

Industrial operations interface prototype for oil & gas production, integrity, reliability, work execution, inspection, HSE and shift operations.

## Run locally

This is a static frontend prototype. Serve the repository root with any static web server.

## Deploy on Render

Create a **Static Site** connected to this GitHub repository.

- Build Command: leave blank
- Publish Directory: `.`
- Branch: `main`

The project has no Docker requirement and no server-side runtime.

## Data note

Operational values in this prototype are synthetic demonstration data. They are not presented as live production or SCADA data.
